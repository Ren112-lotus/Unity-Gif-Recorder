# Changelog

## 1.0.0 — 2026-10-23

- Initial standalone Unity Package Manager release.
- GIF start/stop button in the same row as the existing Game view toolbar.
- F9 shortcut, settings, cancellation, progress and output-file menu.
- Manual recording duration, disk-backed capture and asynchronous GIF encoding.
- Adaptive per-frame palettes and GIF89a LZW compression without external tools.
- Safe cleanup on cancellation, Play mode exit and assembly reload.
